Computer Communication and Network - I

AI Insight Lab

This website was created for our university project at Canadian Institute of Technology. We chose a topic related to AI and Data Science because it is our study field and we wanted the project to feel connected to what we are learning.

The website is simple on purpose. The main goal was not to build a big company website, but to understand how a real website is created, uploaded online, connected to a domain, and secured with HTTPS.

About this project

Our idea was to create a small educational website where first-year students can read about basic AI and Data Science topics. At the same time, the project helped us practice concepts from the Computer Communication and Network course, especially DNS, domain names, HTTPS and website hosting.

We did not want the website to look like a large technology company. We wanted it to look like a realistic student project: clean, understandable and useful for a short live demo.

Main topics

These are the topics we decided to include because they are common in the first steps of AI and Data Science.

Artificial Intelligence

AI is about creating systems that can solve problems, recognize patterns and support decision-making.

Machine Learning

Machine Learning allows a computer to learn from data instead of following only fixed rules.

Data Analysis

Data analysis means cleaning, organizing and understanding data to find useful information.

Data Visualization

Charts and graphs make data easier to read and help people notice patterns more quickly.

Ethics in AI

AI should be used carefully, especially when personal data, privacy or fairness are involved.

How the website is published

For the final version, the website can be uploaded to GitHub Pages. After that, a custom domain can be connected using DNS records. HTTPS can be enabled from the GitHub Pages settings.

Step What we do Why it matters
1 Create repository username.github.io GitHub Pages uses this repository to publish the website.
2 Upload HTML, CSS and JavaScript files These files create the structure, design and small interactions.
3 Add a custom domain The website becomes easier to access and looks more professional.
4 Enable HTTPS The browser shows that the connection is secure.

What we learned

  • How a basic website is structured with HTML, CSS and JavaScript.
  • How GitHub Pages can host a static website for free.
  • Why DNS is needed to connect a domain name with a website.
  • Why HTTPS and SSL/TLS certificates are important for security.

Problems we faced

At first, it was confusing to understand why the website needs separate files such as index.html, style.css and script.js. We also had to learn that JavaScript files should not be opened directly in Windows, because they are used by the browser through the HTML file.

Another challenge was understanding DNS and HTTPS. We solved this by checking the project brief, reviewing the steps for GitHub Pages and testing the website locally before preparing it for upload.
